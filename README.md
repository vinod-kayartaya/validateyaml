# YAML Validator

A web-based YAML validation and conversion tool that helps developers validate YAML syntax and convert it to different formats.

Created and maintained by [Vinod Kumar Kayartaya](https://vinod.co)

## Features

- Validate YAML syntax in real-time
- Convert YAML to:
  - JSON
  - Python dictionary
  - Canonical YAML
- Load YAML content directly from URLs
- Copy converted output to clipboard
- Built-in example for quick testing
- Monaco editor with syntax highlighting

## Usage

1. Enter or paste your YAML content in the input editor
2. Choose your desired output format (JSON, Python, or Canonical YAML)
3. View the converted output in real-time
4. Copy the output using the copy button

You can also:

- Load YAML content from a URL by entering the URL and clicking "Validate URL"
- Load an example YAML by clicking "Load Example"

## Technologies Used

- React.js
- Material-UI (MUI)
- Monaco Editor
- js-yaml parser
